# FoodShare – Food Surplus Optimizer and Redistribution Network

**Share More. Waste Less.**

## About the Project

FoodShare is a Java-based web application designed to support the coordination of surplus food donations between food donors and recipients such as NGOs and charitable organisations.

The application allows users to register, log in, submit food donation details, and raise food requirements. It helps manage donation and request information and identify suitable matches based on food type and quantity.

The project demonstrates how Java programming concepts and web technologies can be used to address a real-world problem: reducing avoidable food wastage.

## Objectives

- Encourage the redistribution of surplus food.
- Connect food donors with organisations and individuals in need.
- Maintain food donation and request records.
- Identify suitable donations and requests based on food type and quantity.
- Demonstrate Java programming concepts through a practical web application.

## Data Structures and Concepts

The project demonstrates the use of fundamental Java data structures and programming concepts:

- **Linked List:** Dynamic management of donation records.
- **Queue:** First-In-First-Out processing of requests.
- **Stack:** Demonstration of Last-In-First-Out operations.
- **Interfaces:** Abstraction and separation of service contracts from implementation.
- **Exception Handling:** Managing application errors.

## Application Workflow

1. A user registers and logs in.
2. The user accesses the FoodShare dashboard.
3. A donor submits surplus food details, or a recipient submits a food requirement.
4. The application processes the submitted information.
5. Suitable donation and request details are compared.
6. Records are maintained through database connectivity.

## Project Scope

FoodShare is an academic prototype developed as part of the MCA Java practical curriculum. It focuses on demonstrating Java programming, web application development, data structures, Servlet technology, and database connectivity.

It is a coordination platform and does not directly provide food delivery or transportation services.

## Conclusion

FoodShare demonstrates how a Java-based web application can support food donation and redistribution by organising donation and request information. It combines core Java concepts, web technologies, data structures, and database connectivity to provide a practical solution concept for reducing food wastage.
